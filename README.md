# Combined Reporit

This repository combines:

- `server-script-manager/`: the Python manager with disk routines, cleanup gates, native connector support, and forecasts.
- `reporitor-ticker/`: the PowerShell Reporitor ticker package.
- `integration/ssm.reporitor.example.toml`: a combined configuration example.
- `COMBINED-REPORIT.md`: the report explaining the combined operating model.

The Python copy has been extended with the `reporitor_ticker` routine so SSM can forecast and run the ticker when PowerShell is available.
