# Changelog

All notable changes are recorded here. The project uses semantic versioning while the public API
is forming.

## 0.5.0 — 2026-09-07

- Added optional LAN graphics administrators that advertise all thirteen coat capacities.
- Added a fixed, checksummed, versioned advertisement codec and TTL-one IPv4 multicast discovery.
- Added explicit out-of-band node trust; discovery traffic never authorizes remote work.
- Added capability-, RTT-, slot-, and coat-aware scheduling for 128×128 massive-unit leases.
- Bound leases to node boot, frame, seed, coordinates, feature bits, input digest, and deadline.
- Added fail-closed proof/result validation, duplicate suppression, and exact local fallback work.
- Added real UDP loopback plus corruption, trust, expiry, restart, capacity, and proof tests.

## 0.4.0 — 2026-09-06

- Added 128×128 massive classification units over 64 established 16×16 leaf tiles.
- Added deterministic C++ resolution/cost classification and batch-level FULL escalation.
- Added safe sparse-queue rebalancing and indirect dispatch argument generation.
- Added packet/leaf, massive aggregation, and dispatch-governor GLSL compute stages.
- Added checked C++/GLSL record layouts, tests, and classification integration documentation.

## 0.3.0 — 2026-09-06

- Promoted the implementation into a standalone Git repository.
- Added deterministic correctness tests and cross-platform CI.
- Latched camera and topology discontinuities until a new FULL seed is committed.
- Documented the OpenGL execution boundary and proof protocol.

## 0.2.0 — 2026-09-06

- Reframed the system as a correctness-first Full-Path Graphics Relay.
- Added native FULL seeding, reduced-cost relay planning, selective native refinement, and a
  fail-closed proof gate.
- Added temporal classification and resolve GLSL compute stages.

## 0.1.0 — 2026-09-06

- Added EIN capability handles, thirteen memory coats, fence-gated retirement, typed scheduling,
  compute LOD culling, indirect draw contracts, and the trace demonstration.
